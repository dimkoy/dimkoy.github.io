Author. Every line counted on this page was written by Dmitrii Cherviakov, the sole iOS developer on the project — pure SwiftUI and The Composable Architecture (TCA).

Methodology. Source — the git history of the main branch. Only *.swift files are counted; the generated Localizable.xcstrings (77k lines of JSON), assets and project files are excluded. The cumulative curve is built from git log --numstat and cross-checked against an exact line count at the end of each month — 0.3% discrepancy.

Builds. The project follows trunk-based development: every non-merge commit to main is a shippable build carrying a feature or a fix, so build counts double as delivery cadence.

Features. A ticket counts as a feature when at least one of its commits is not a fix; its size is the total lines added across the ticket's commits, attributed to the month where most of that code was written. Ticket IDs are omitted.

Lines of code are a proxy metric — sensitive to style and refactoring. That's why build counts and feature counts are shown alongside: the growth conclusion rests on more than one signal.
